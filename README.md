# Todo Tornado

A clean **Next.js App Router TODO app** with localStorage persistence, progress stats, and add / edit / complete / delete flows.

## Features

- UUID task ids
- Toggle complete, inline edit, delete
- Hero progress summary
- localStorage persistence

## Tech

Next.js (App Router) · React · CSS

## Run

```bash
git clone https://github.com/bugship/todo-tornado.git
cd todo-tornado
npm install
npm run dev
```
